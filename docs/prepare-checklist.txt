# 智慧配送解决方案开发前配置清单（修订版）

> 本修订版按“四台设备分工”整理：Windows 控制机、Ubuntu 开发机、Ubuntu 服务端、阿里云穿透端。
> 明文密码、frp token、数据库密码、JWT 密钥、高德 Key 等敏感内容不得写入 Git 仓库，统一通过 `.env` / 环境变量 / 机器本地配置管理。
> 真实 `.env` 文件不要提交 GitHub；只提交 `.env.example`。

## 1. 项目基础信息

项目名称：智慧配送解决方案

GitHub 仓库地址：`https://github.com/LPZ55556/xlt-delivery-system`

主要开发方式：Codex 通过 SSH 连接 Ubuntu 开发机进行开发；Ubuntu 服务端负责部署运行；Windows 只作为控制机。

技术栈要求：React Native、Next.js / React、NestJS、PostgreSQL、Redis、Docker Compose、FRP。

## 2. 四台设备分工

### 2.1 Windows 控制机

用途：打开 Codex、SSH、浏览器、GitHub，不保存项目源码和开发依赖。

### 2.2 Ubuntu 开发机

用途：Codex SSH 连接这台机器进行开发、测试、构建。

Ubuntu 开发机系统：Ubuntu 22.04

Ubuntu 开发机局域网 IP：`192.168.31.129`

Ubuntu 开发机 SSH 用户：`root`

SSH 密码：不写入仓库，由用户在本机安全保存。

项目源码目录：`/home/projects/xlt-delivery-system`

需要安装：Git、Node.js LTS、pnpm、Docker、Docker Compose、Android SDK / Android Studio 或命令行构建环境。

### 2.3 Ubuntu 服务端

用途：实际运行系统，承载 API、Web 后台、PostgreSQL、Redis、frpc。当前阶段不要操作服务端。

Ubuntu 服务端系统：Ubuntu 22.04

Ubuntu 服务端局域网 IP：`192.168.31.128`

Ubuntu 服务端 SSH 用户：`root`

SSH 密码：不写入仓库，由用户在本机安全保存。

### 2.4 阿里云穿透端

用途：只运行 frps，不部署业务后端、不部署数据库、不部署 Web 后台。

frps 公网地址：`42.121.105.101`

frps 通信端口：`7000`

frps HTTP vhost 端口：`8080`

frps dashboard：仅阿里云服务器本机可访问，不开放公网。

## 3. 域名与访问地址

主域名：`lnize.top`

API 域名：`api.lnize.top`

Web 后台域名：`admin.lnize.top`

当前访问地址：

```text
App 请求 API 地址：http://api.lnize.top:8080
Web 后台访问地址：http://admin.lnize.top:8080
```

## 4. 数据库与 Redis 配置

数据库类型：PostgreSQL

数据库名：`delivery_db`

数据库用户：`delivery_user`

数据库密码：通过环境变量 `POSTGRES_PASSWORD` 配置，真实密码不写入项目文档和代码仓库。

数据库连接地址：通过环境变量 `DATABASE_URL` 配置。

Redis 密码：通过环境变量 `REDIS_PASSWORD` 配置，真实密码不写入项目文档和代码仓库。

PostgreSQL 和 Redis 只允许本地服务访问，不开放到公网。

## 5. App 与 Web 配置

Android App 包名：`com.xlt.delivery`

App 名称：`小灵通`

API_BASE_URL：通过 `MOBILE_API_BASE_URL` 或 `API_BASE_URL` 配置。

高德 Android Key：通过环境变量 `AMAP_ANDROID_KEY` 或构建配置注入，真实 Key 不写入项目文档和代码仓库。

后台名称：小灵通管理后台

管理员账号、管理员密码和进价查看安全密码通过首次初始化流程设置，不在环境变量中预置明文密码。

## 6. 安全要求

- 不提交真实 `.env`、`.env.production`、frp token、数据库密码、JWT_SECRET、高德 Key、SSH 密码、Android keystore。
- App 开单时不能显示商品进价。
- 查看商品进价必须有权限，并输入进价查看安全密码。
- 进价查看、订单修改、订单作废和删除数据等重要操作必须写入审计日志。
- PostgreSQL、Redis、frps dashboard 不允许开放公网。
- 所有 API 后续必须有登录认证。
- 所有敏感配置必须通过环境变量读取。
