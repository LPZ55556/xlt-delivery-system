## 14. 给 Codex 的说明

本项目采用四设备分工：

1. Windows 控制机
只用于打开 Codex、SSH 和浏览器，不保存项目代码。

2. Ubuntu 开发机
Codex 通过 SSH 连接这台机器进行开发。项目源码、依赖安装、代码修改、测试、Android 构建都在这台机器上完成。

3. Ubuntu 服务端
用于部署运行系统。运行 NestJS API、Next.js Web 后台、PostgreSQL、Redis 和 frpc。外部用户通过阿里云 frps 穿透访问这台服务端。

4. 阿里云穿透端
只运行 frps，不部署业务代码、不部署数据库、不部署 Web 后台。

项目需要提供：

1. docker-compose.yml
2. docker-compose.dev.yml
3. docker-compose.prod.yml
4. .env.example
5. frpc.example.toml
6. 本地服务器部署说明
7. API_BASE_URL 配置项
8. 数据库连接配置项
9. Redis 配置项
10. 数据库备份脚本 backup-db.sh
11. 数据库恢复脚本 restore-db.sh

不要在代码中写死公网 IP、frp token、数据库密码、JWT 密钥、高德 Key。

## 15. 迁移要求

项目后期需要支持迁移到其他设备部署，因此必须满足：

* 代码放 GitHub
* 配置放 .env，不写死在代码里
* 服务用 Docker Compose 管理
* 数据库可通过备份和恢复脚本迁移
* frpc 配置提供 example 模板
* PostgreSQL 和 Redis 不开放公网
* App 端 API 地址通过配置项管理
* Web 后台地址通过配置项管理
* 开发环境和部署环境分离
